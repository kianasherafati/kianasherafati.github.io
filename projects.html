ERP Text-to-SQL with RAG

A retrieval-augmented pipeline that translates English ERP reporting questions into SQL Server T-SQL using relevant schema context.

PythonRAGSQL ServerStreamlit
View source ↗
Implementation details
  • Combined BGE-M3 dense retrieval with MiniLM semantic/lexical retrieval and foreign-key expansion, followed by BGE-Reranker-v2-M3 reranking.
  • Generated SQL with Qwen2.5-Coder-7B-Instruct and added schema-aware validation and parameterized, read-only previews.
  • In thesis experiments, reranking increased macro schema-retrieval recall at 20 tables from 75.27% to 80.77%; this is a retrieval metric, not SQL accuracy.
  • The public repository contains reusable components and a synthetic demo; company schemas and connection details are excluded.
