\entry{Natural Language to SQL Query Generation for ERP Systems\newline
  Using Retrieval-Augmented Generation (RAG)}{2026}
\detail{Undergraduate thesis \textbar\ Successfully defended}
\detail{Supervisor: Dr. Masoumeh Taromi Rad \textbar\
  \href{https://github.com/kianasherafati/erp-text2sql-rag-portfolio}{Public repository}}
\begin{itemize}
  \item Built a RAG pipeline that translates English ERP reporting questions
    into T-SQL for Microsoft SQL Server, using schema context to resolve
    abbreviated identifiers and complex table relationships.
  \item Combined BGE-M3 dense retrieval, MiniLM hybrid retrieval, and
    foreign-key expansion. Ranked candidate tables with BGE-Reranker-v2-M3
    to supply schema context to Qwen2.5-Coder-7B-Instruct.

    per question, rose from \textbf{75.27\% to 80.77\%}. Reviewed query
    execution and result correctness separately.
  \item Implemented schema-aware SQL validation and parameterized, read-only
    previews in Streamlit. Released reusable components and a synthetic demo.
\end{itemize}
